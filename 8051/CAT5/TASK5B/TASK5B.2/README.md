### Core Logic

* **1. Dynamic Timer Reload Modification**  
  Square waves of varying frequencies are generated by dynamically loading different 16-bit values into Timer 0 registers `TH0` and `TL0`:
  ```c
  void set_frequency(unsigned char mode) {
      switch(mode) {
          case 1: reload_high = 0xEE; reload_low = 0x00; break;
          case 2: reload_high = 0xFC; reload_low = 0x66; break;
          case 3: reload_high = 0xFE; reload_low = 0x33; break;
          case 4: reload_high = 0xFF; reload_low = 0x00; break;
      }
  }
  ```

* **2. Symmetrical Pin Toggling**  
  In the ISR, `OUTPUT = ~OUTPUT;` toggles Port 1 Pin 1 on every timer overflow, maintaining a 50% duty cycle while altering output frequency.

### Inference
Frequency synthesis on the 8051 was validated. Altering timer reload counts directly scales output square wave frequency while maintaining precise 50% duty cycle timing.
